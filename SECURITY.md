# Security policy

## Reporting a vulnerability

If GitHub private vulnerability reporting is enabled, report security issues
through [GitHub Security Advisories](https://github.com/shihaab453/rungraph/security/advisories/new).

If that option is unavailable, open an [issue](https://github.com/shihaab453/rungraph/issues)
asking for a private reporting channel. Do not include vulnerability details,
exploit code, credentials or other sensitive information in the public issue.

Non-sensitive hardening suggestions and documentation fixes can be reported
in a regular issue.
